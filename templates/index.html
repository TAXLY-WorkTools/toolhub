📥 使用工具

  1. 打开 pack.html，填信息、拖代码和截图，一键生成 zip
  2. 自动跳 upload.html，确认信息后点提交
  3. 跳 GitHub Issue，在评论区拖拽 zip 上传
  4. 机器人自动处理，1-2 分钟后出现在列表
