上传流程
  1. 填写左侧工具信息
  2. 点击下方按钮跳转 GitHub
  3. 选择所属部门和功能分类（下拉框手动选）
  4. 在评论区拖拽上传 .zip 压缩包（完整上传模式）
  5. 点击 "Submit new issue"，系统自动处理
注意事项
  • 工具名称创建后不可修改
  • 部门和功能分类在 GitHub 页面选择
  • 完整上传需在评论区上传压缩包
  • 快速创建空库无需上传文件
  • 上传后可在工具详情页点击"编辑此工具"修改
