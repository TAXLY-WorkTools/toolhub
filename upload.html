提示：以上信息由打包器自动预填，如需修改请直接编辑。工具名称创建后不可修改，请仔细确认。
上传流程
  1. 确认工具信息：检查上方工具名称和描述是否正确
  2. 点击下方按钮：跳转到 GitHub 新建仓库页面
  3. 创建仓库：在 GitHub 页面点击 "Create repository"（仓库名和描述已自动填入）
  4. 上传压缩包：在新建仓库的评论区（Issues）上传打包器生成的 zip 文件
  5. 提交评论：点击 "Comment" 按钮，系统自动识别并处理上传
  6. 等待同步：约 1-2 分钟后，工具会自动出现在主页列表中
注意：GitHub 评论区单文件上传上限为 25MB，建议压缩包不超过 20MB。跨境上传速度可能较慢，几 MB 的文件也可能需要数分钟，请耐心等待。

快速创建空库
占坑模式说明：仅创建一个空的 GitHub 仓库，用于预留工具名称位置。后续可以通过打包器上传完整内容。适合工具尚未开发完成但需要先占用名称的场景。
后续操作
  1. 空库创建成功后，仓库会出现在组织中，但主页不会显示（因为没有 README）
  2. 开发完成后，使用打包器生成完整上传包
  3. 上传到已有仓库：在该仓库的评论区上传 zip 文件即可，无需重复创建
